# 序言

大家好，我是老马。

不知道各位小伙伴是否和我一样，生活中会有下面的疑惑。

我到底应该活成什么样的人生？

我要怎么做才能实现自己理想的生活呢？

我在逃避什么？是什么阻碍着我成为理想中的自己？

如果有的话，可以试一下下面的方法。

# 提示词

直接把下面的内容给聊天大模型就行。

```
请基于油管大神Dan Koe的Human3.0人生模型，帮我做一次完整的人生规划。
从以下四个象限进行分析，分别判断我目前更接近L1,L2,L3，并给出具体依据:
心智-Mind:认知、情绪、思维模式、自我意识
身体-Body:健康、睡眠、运动、精力
精神-Spirit:价值观、意义感、人际关系、人生方向
事业-Vocation:工作、收入、技能、商业能力、自由度

请先像一位专业的人生战略顾问一样采访我，每次只问我1个最重要的问题，并根据我的回答继续追问，直到你认为已经足够了解我。

过程中重点识别:
我真正想要的人生
我的行为与目标之间的矛盾我反复拖延和逃避的问题
限制我的生活习惯、身份认同和环境我最有潜力、但尚未充分开发的优势

采访结束后，请帮我结构化输出:
我的Human3.0四象限等级、核心问题、最大杠杆点，以及一份具体可执行的90天人生进化指南。
不用顾及我的情绪，不要说正确的废话。发现我有自欺、矛盾或逃避时，请你直接指出来。
OK，现在开始，只问第一个问题。
```

然后如实回答一些问题。

# 整体情况

我和 chatGPT 聊了一下，问了我 26 个问题，感觉收获还是挺多。

下面是对我的一些评价：

| 象限              | 当前等级           | 核心判断                       |
| --------------- | -------------- | -------------------------- |
| **Mind 心智**     | **L2 → L3 边缘** | 认知能力、反思能力较强，但现实反馈不足        |
| **Body 身体**     | **L1**         | 明显短板，正在透支未来                |
| **Spirit 精神**   | **L2 → L3 边缘** | 价值观非常清晰，但行动与价值观尚未完全统一      |
| **Vocation 事业** | **L2**         | 技术能力强、长期主义强，但商业闭环和现实市场验证不足 |

更准确一点：

> 上限明显高于当前人生状态，但生活系统没有把这些能力转化成现实结果。

# 自欺

我觉得关于自欺的部分很有趣，这里记录一下。

## 自欺1

虽然我做了很多年的开源+写博客。但是一直没有太多的成长，或者说世俗意义的成功。

GPT 说我有一个非常高级的逃避方式：用创造代替验证。

> 简单点说，就是闭门造车的研究一堆技术。总是觉得这样自己就进步了，实际上并没有真实的接受真实世界的反馈。

接下来，必须面对这种人生现实。

自己的工具做得再好，如果没有用户、影响力和收入，它距离你的最终人生目标还有多远？

## 自欺2

我说最近因为 AI 的发展，觉得写作，乃至写代码都变的很无趣。

因为我写的，AI 也能写，那我写的还有什么意义呢？

我的第二个自欺是：

> 把“AI 改变内容”当成停止表达的理由

接下来，我也确实应该放弃以前的信息知识，因为 AI 要比大部分写的更好。

更多的，应该从信息，转变为：

我的经历、我的实践、我的判断、我的失败、我的旅行、我的投资决策、我的长期人格信用。

也就是一些个性化的东西，属于“我”的一些内容。


# 结语

最大的感概就是自己一直得过且过，再过一个“70分”的人生。

然后等待着有一天中年危机的到来。

想改变，但是又无力改变的感觉。

就像一个人站在沼泽地上，看着自己沉下去。

于是，接下来我想尝试着做一点改变，记录一些自己的思考。

可能纯技术的文章就会少很多。
